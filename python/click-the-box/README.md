# Click The Box

A simple click-the-box game built using **Python’s Pygame module**.
This project demonstrates **event handling**, **collision detection**, and **basic game loop mechanics** in a clean, beginner-friendly way.

Minimal UI. Functional gameplay. Straight to the point.

---

## What This Game Does

* Spawns falling boxes at random positions
* Detects mouse clicks on boxes
* Increases score when boxes are clicked
* Decreases score when boxes fall off-screen
* Continuously updates gameplay in real time

---

## Game Features

* Real-time rendering using Pygame
* Mouse-click collision detection
* Dynamic box spawning system
* Score tracking system
* Smooth frame updates with controlled FPS

---

## Requirements

* Python 3.x
* Pygame

Install Pygame using:

```bash
pip install pygame
```

---

## How to Run

```bash
python main.py
```
